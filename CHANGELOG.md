## [0.2.0] — 2026-10-05

### Added

- Moved out of `sxnnyside-skills` into its own repository; distributed as a GitHub Release asset.
- Added the URL contract (`/site`), the i18n core (`/i18n`), `<SeoHead />`, base styles and `sxnnyside-astro-check init`.
- Added the reconciled asset pipeline (`/asset-pipeline`), sitemap policy, `envLoader` and the CSP contract gate.
